# @gardusi-gustavo/ts

TypeScript reference package: DOM helpers, text helpers, tests, a React example,
and npm release notes.

## Layout

| Path | Holds |
| --- | --- |
| `src/` | publishable TypeScript |
| `src/test/` | Node test runner tests |
| `examples/react-app/` | full React + Vite demo |
| `docs/` | usage and release notes |

## Build

```bash
npm install
npm run ci
```

JavaScript is build output only. Source is TypeScript.
